# Getting help

| You want to | Go to |
|---|---|
| Ask how something works, or get help building and using LibreScreen | [Discussions › Q&A](https://github.com/renatoasterio/LibreScreen/discussions/categories/q-a) |
| Propose or shape an idea | [Discussions › Ideas](https://github.com/renatoasterio/LibreScreen/discussions/categories/ideas) |
| Report a bug | [New issue](https://github.com/renatoasterio/LibreScreen/issues/new/choose) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md) |
| Contribute code, translations or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before opening a bug report, check that you are on the latest commit of `main` and search the existing issues. Reports
are much easier to act on with your macOS version, your Mac model and display setup, and the steps that lead to the
problem.

LibreScreen is a small project without a support team, so please allow a few days for an answer.
